What writing Ernest felt against the principles, a line each, a queue: a line is carried to Ernest's `language_feedback.md` by copy, Ernest's verdict comes as `language_feedback_reply.md` under Ernest's `docs/tmp/`, the log here cites Ernest's number, and the line then goes; a line not answered, or not agreed with, stays with the verdict and the reason beneath it. The lines are numbered on from the seventeen of the rounds before, all answered; the lines below were found on 2026-11-02 against the archive `0.9.0+181641e2`, building milestone 2's item 1, the refusal's form.

18. **`Tcp.listenTls` answers a file it cannot read as `Denied`, naming no file, the same value as a bind it may not make.** `Tcp.listenTls("127.0.0.1", 8443, Path("cert.pem"), Path("cert.pem"))` with `cert.pem` at mode `0o000` answers `Left(Denied)`, as `Tcp.listen("127.0.0.1", 80)` does as no root; a file it refuses names itself, `Other("cert.pem: no certificate")`. The caller cannot tell which file failed, or whether the port did, so a line that says what to do at `Denied` on a port below 1024 can name the wrong cause. Principle 1, and 3: a failure visible where it happens. Ask: a file `listenTls` cannot read is answered as a file it refuses is, `Other` naming the file and the reason, `Other("cert.pem: Denied")`, and E.18 says so.

19. **G.6 does not say which characters `Json.format` escapes.** `Json.format(Json.Text("a\u{0}b\u{7f}c\td"))` writes `"a\u0000b` then U+007F bare, then `c\td"`: U+0000 to U+001F escaped, U+007F not, which a program that shows a refused string must know. Principle 1: the page is silent and the probe is the only answer. Ask: G.6 states what `format` escapes.

20. **G.6 has no one-line writer.** `Json.format` of a four-member object writes five lines, a layout, so a message that quotes a value, `listeners must be an array: {` and three lines more, runs over lines, and a program that wants one line would write a second JSON writer, a library's work. Principle 1: a reader who knows Erlang predicts the host's `json:encode` beside `json:format`. Ask: `Json.encode : (Value) -> String`, one line, the host's `json:encode`, and G.6 says so.
