# Ernest module AccessLog

The access log: one process that writes each response a connection tells
it as a line of Common Log Format, appended to the file by its path in
batches (design §8).

The program starts it once, with `start`, and each connection sends it an
`Entry` for each response it has written. The process holds no file open:
each batch is one `Fs.append`, which opens the file by its path, so that a
file renamed by a rotation is begun anew at the next batch. A batch is
every message waiting when the process takes one, so that a busy server
opens the file once for many lines; nothing but what has arrived decides
it.

`Flush` is answered once every entry sent before it is written, which the
program asks at its end. `line` is the line an entry is written as.

## Examples

The line of an entry, its time in UTC:

```ernest
AccessLog.line(AccessLog.Entry(remote = "192.0.2.7",
                               time = 784111777000,
                               request = Some("GET /index.html HTTP/1.1"),
                               status = 200,
                               size = 2326))
// => Some("192.0.2.7 - - [06/Nov/1994:08:49:37 +0000] \"GET /index.html HTTP/1.1\" 200 2326")
```

## AccessLog.LogMsg

```ernest
type LogMsg =
    Entry(remote : String, time : Int, request : Optional(String), status : Int, size : Int)
  | Flush(Reply(Unit))
```

What the access log takes: the entry of a response written, its remote
address, the time it was written in milliseconds since the epoch, its
request line as the client wrote it, none where no head was read, its
status and the size of its body in bytes; and a flush, answered once
every entry sent before it is written or lost.

## AccessLog.start

```ernest
AccessLog.start(path : Path, ms : Int) : Address(LogMsg)
```

The access log's process started, appending its lines to the file at
`path`, each append within `ms` milliseconds; an append that fails is
said on standard error, and its lines are lost.

### Examples

```ernest
let log = AccessLog.start(Path("access.log"), 5000);
send(log,
     AccessLog.Entry(remote = "192.0.2.7",
                     time = Clock.now(),
                     request = Some("GET / HTTP/1.1"),
                     status = 200,
                     size = 4));
Address.callForever(log, AccessLog.Flush)
// => Unit
```

## AccessLog.line

```ernest
AccessLog.line(message : LogMsg) : Optional(String)
```

An entry's line in Common Log Format, without its line feed:
`remote - - [time] "request" status size`, the time in UTC,
`06/Nov/1994:08:49:37 +0000`, and the request `-` where there was none;
`None` for a `Flush`.

The request is written so that no client forges a line: `"` as `\"`, `\`
as `\\`, and each byte outside U+0020 to U+007E as `\x` and two
upper-case hexadecimal digits.

### Examples

```ernest
AccessLog.line(AccessLog.Entry(remote = "::1",
                               time = 0,
                               request = None,
                               status = 408,
                               size = 15))
// => Some("::1 - - [01/Jan/1970:00:00:00 +0000] \"-\" 408 15")
```
