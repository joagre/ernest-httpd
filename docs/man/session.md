# Ernest module Session

One session: a visitor's program under a terminal, kept for the
visitor's cookie across the shells that attach to it, and ended with a
close code (design §12).

`serve` is the session's whole life, in a process the sessions spawn. It
starts the shell's command under a terminal of the page's size, reads
the terminal through a reader of its own, which alone calls `Os.read`,
and writes the visitor's keys to it through a writer of its own, which
alone calls `Os.write`. The reader reads once for each `Read` the
session sends: at an attach, and then once the attached shell has
written the last piece of output, its `Written`, so that a page that
takes its output slowly, or no page, holds the program back as a full
terminal does, and the piece a read answered after a detach is held for
the next shell. Keys that come while a write is under way are held,
joined, up to `message-limit` bytes, and keys that would pass them
dropped whole, so that the session never waits on a program that reads
nothing; a write past its deadline is waited out before the next, so
that the program's input holds one write at most. One shell is attached
at a time: an attach takes the session over, and the shell attached
before is told `Ended(4002)`. Each shell attached is told so, `New`
where it is the first since the session's start and `Joined` after it.

The session lives `lifetime` milliseconds from its start, its last key or
its last `Extend`, kept by one alarm at a time, and the attached shell is
told `Warning` `warning` milliseconds before the end. It ends with a
close code: 4001 at its deadline, 4004 at its program's exit or the
visitor's `Stop`, 4003 where its program cannot start, 1011 where its
reader or its writer ends first, and the code an `End` gives. As its end
begins it calls the sessions, `Ending`, which answer once its cookie
names it no more; then it ends its writer, hangs its terminal up, reads
on until its program exits or `hangup` milliseconds pass, kills the
program where it has not exited, and tells every shell whose attach has
reached it the end's code.

## Session.Told

```ernest
type Told =
    Attached(session : Address(SessionMsg), attachment : Attachment)
  | Unavailable
  | Output(Bytes)
  | Warning(Int)
  | Ended(Int)
```

What a shell is told by a session or by the sessions: it is attached,
with the session's address and whether it is the session's first shell;
no session is to be had; the program's output; a warning, with the
seconds left; and the session's end, with the close code.

## Session.SessionMsg

```ernest
type SessionMsg =
    Attach(Address(Told))
  | Detach(Address(Told))
  | ShellEnded(Down)
  | Keys(Bytes)
  | Written(Address(Told))
  | Resize(Terminal.Size)
  | Extend
  | Stop
  | End(Int)
  | Answered(Either(Io.Error, Os.Output))
  | ReaderEnded(Down)
  | Wrote
  | WriterEnded(Down)
  | Alarm(Int)
```

What a session takes: a shell's attach and its detach, the attached
shell's end, the visitor's keys, a shell's word that it has written a
piece of output, a resize of the terminal, an extension of the deadline,
the visitor's stop and an end with a close code, which the sessions
send; what its reader's read answered and the reader's end; its writer's
word that a write is done and the writer's end; and the deadline's alarm.

## Session.Ending

The call a session makes of the sessions as its end begins, with its own

## Session.serve

```ernest
Session.serve(shell : Config.Shell, timeouts : Config.Timeouts, size : Terminal.Size, sessions : Address(Ending)) : Unit receiving SessionMsg
```

The session's life: the shell's command started under a terminal of the
size, the first word the program and the rest its arguments, served to
the shells that attach until its end with a close code, at whose
beginning it calls `sessions`; then it returns. A command that cannot
start is said on standard error, and the session ends with 4003 at its
attach.
