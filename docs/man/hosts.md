# Ernest module Hosts

The hosts: what a request's host decides before the site serves it, the
canonical host served, a redirect host and the redirect listener
answered 301, a host that is neither 421, and the ACME challenge served
on the redirect listener (design §9).

A connection asks `decide` for each request it does not refuse itself,
and serves the request from the site where the answer is `Served`;
otherwise it writes the answer's response, as it writes the site's. The
connection is given the challenge site where it is the redirect
listener's, and `None` on another.

A request's host is read from its target where the target is in
absolute form, and from its `Host` header otherwise, `host`; it is
compared with the configuration's hosts, their ports dropped as its own
is, `Config.withoutPort`, and in any case, and a request that names none
is the canonical host's. A redirect's `Location` is always on the
canonical host, written as the configuration writes it, its port among
it, over HTTPS.

## Examples

A redirect host's request answered 301 to the canonical host:

```ernest
let text =
    "{\"listeners\": [{\"kind\": \"plain\", \"address\": \"::\", \"port\": 80}],"
        <> " \"root\": \"site\", \"canonical-host\": \"ernest-lang.org\","
        <> " \"redirect-hosts\": [\"www.ernest-lang.org\"],"
        <> " \"timeouts\": {\"head\": 1, \"idle\": 1, \"write\": 1, \"file\": 1},"
        <> " \"limits\": {\"request-line\": 1, \"headers\": 1, \"connections\": 1,"
        <> " \"connections-per-address\": 1}, \"content-types\": {}, \"headers\": {},"
        <> " \"access-log\": \"access.log\"}";
let request =
    Http.Request(method = "GET",
                 target = "/docs?page=2",
                 version = Http.Version(major = 1, minor = 1),
                 headers = [Http.Header(name = "Host", value = "WWW.ernest-lang.org:80")]);
Either.map(Config.parse(text), fn(config) = Hosts.decide(config, None, request, 1000))
// => Right(Hosts.Answered(#(Http.Response(version = Http.Version(major = 1, minor = 1), status = 301, headers = [Http.Header(name = "Location", value = "https://ernest-lang.org/docs?page=2")]), <<>>)))
```

## Hosts.Answer

```ernest
type Answer = Served | Answered(#(Http.Response, Bytes))
```

What a request's host decides: the site serves the request, or the
response answers it instead, its body beside it.

## Hosts.host

```ernest
Hosts.host(request : Http.Request) : Optional(String)
```

The request's host, its port dropped, as the client wrote it: the
authority of a target in absolute form, and otherwise the value of the
first `Host` header; `None` where the target is not in absolute form and
there is no `Host` header.

The port is a `:` and digits alone after it at the host's end, as
`Config.withoutPort` drops it; any other tail stands, and the host then
matches none of the configuration's.

### Examples

```ernest
let request =
    Http.Request(method = "GET",
                 target = "/",
                 version = Http.Version(major = 1, minor = 1),
                 headers = [Http.Header(name = "Host", value = "[::1]:8080")]);
Hosts.host(request)
// => Some("[::1]")
```

## Hosts.decide

```ernest
Hosts.decide(config : Config.Config, challenge : Optional(Static.Site), request : Http.Request, ms : Int) : Answer
```

What the request's host decides before the site serves it, on a listener
whose challenge site is `challenge`, the redirect listener's, or `None`
on another; each read of the file system bounded by `ms` milliseconds.

In this order: a host that is neither the canonical host nor a redirect
host answers 421. On the redirect listener a request whose path and
query begin with `/.well-known/acme-challenge/` is served from the
challenge site with the rest of its target, a 301 the site answers being
404, and every other request answers 301; on another listener a redirect
host's request answers 301, and the canonical host's is `Served`.

A 301's `Location` is `https://`, the canonical host and the target's
path and query as written, and it has no body; where the target is in
neither origin nor absolute form, it answers 400 instead. A `HEAD`'s
response has its body dropped, as `Static.withoutBody` drops it.
