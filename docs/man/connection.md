# Ernest module Connection

A connection: a socket a listener accepted, served one request at a time
in the process that owns it, until it closes (design §6).

`serve` is the connection's whole life. It waits for a request within the
idle deadline, reads its head within the head deadline, refuses what the
server does not serve, a version, a host, a body, and answers the rest as
its host decides, `Hosts.decide`, from the static site where the host is
served, or by the shell where the server has sessions and the target's
path is the shell's. Every response carries `Date` and the
configuration's headers, and is written within the write deadline; the
connection is kept for the next request, the bytes after the head
carried over, or closed, as HTTP/1.1 and HTTP/1.0 have it.

A request on the shell's path is answered as `Shell.handshake` says: a
refusal closes the connection, and after the 101 the connection is the
shell's, `Shell.serve`, until it closes.

On a socket a TLS listener accepted, the first read runs the handshake,
within the idle deadline, and a handshake that fails closes the
connection as a read that fails does, without a response.

Each response written is told to the access log as an entry, and the
listener is told when a head is read and when its response is written,
so that the program's end ends an idle connection and not one serving a
request; after a 101 it is told that the connection is a shell, which
its end closes with 1001.

## Connection.Server

```ernest
type Server =
    Server(config : Config.Config,
           site : Static.Site,
           challenge : Optional(Static.Site),
           log : Address(AccessLog.LogMsg),
           sessions : Optional(Sessions.Sessions))
```

What every connection of a listener shares: the configuration, the site
its requests are served from, the challenge site on the redirect
listener and `None` on another (design §9), the access log's address,
and the sessions where the configuration has a shell (design §12).

## Connection.Told

```ernest
type Told = RequestRead(Process) | ResponseWritten(Process) | Upgraded(Address(Shell.ShellMsg))
```

What a connection tells its listener: a request's head read, and its
response written and told to the log, with its own process; and, after
a 101, that it is a shell, with its own address, by which the
listener's end closes it (design §7).

## Connection.serve

```ernest
Connection.serve(socket : Address(Tcp.SocketMsg), server : Server, listener : Address(Told)) : Unit receiving Shell.ShellMsg
```

The connection's life on the socket: each request read, answered and
told, until the connection closes; then it returns.

The connection closes without a response where the client sends nothing
within the idle deadline or closes, and after a response that refuses a
head or a request, after a 1.1 request that asks it to close, and after
a 1.0 request that does not ask it to keep alive; after a 101 it closes
when its shell does.
