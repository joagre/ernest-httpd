# Ernest module Listener

A listener: the connections of one listening socket, each accepted
within the caps and served in a process of its own, and ended in order
at the program's end (design §7).

`serve` is the listener's whole life, in a process of its own. It
spawns an acceptor, which alone calls `Tcp.accept`, one connection each
time the listener asks, and gives it each socket; the listener itself
waits on its mailbox alone, so that a `Stop` is taken at once. It
counts its connections by what they tell it and by their ends: in all,
where at the cap it asks for no accept until one ends, and by remote
address, where a socket past the cap is closed at once. Each connection
is given its socket and the listener's address, adapted to `Told`.

Told to `Stop`, the listener ends the acceptor, closes the listening
socket, ends each connection that waits for a request, lets each that
serves one write its response and then ends it, tells each that has
become a shell to close with 1001, as a session tells its shell, and
returns once every connection has ended.

## Listener.ListenerMsg

```ernest
type ListenerMsg =
    Accepted(Either(Io.Error, Address(Tcp.SocketMsg)))
  | AcceptorEnded(Down)
  | Told(Connection.Told)
  | ConnectionEnded(Down)
  | Retry(Int)
  | Stop
```

What a listener takes: an accept's outcome, the acceptor's end, what a
connection told it, a connection's end, the alarm to ask for an accept
again after one failed, and the request to stop, which the program's
end sends.

## Listener.AcceptorMsg

```ernest
type AcceptorMsg = Accept
```

What the acceptor takes: the request to accept one connection.

## Listener.serve

```ernest
Listener.serve(socket : Address(Tcp.ListenerMsg), server : Connection.Server) : Unit receiving ListenerMsg
```

The listener's life on the listening socket: connections accepted
through an acceptor within the caps of `server`'s configuration, each in
a process of its own, until a `Stop`; then the acceptor ended, the socket
closed and every connection ended in order, and it returns. An acceptor
that ends before the stop ends the listener, which closes the socket and
returns.
