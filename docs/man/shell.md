# Ernest module Shell

A shell: a connection upgraded to a WebSocket on the shell's path, which
carries a visitor's terminal between the page and the visitor's session
(design §11).

`handshake` decides whether a request on the shell's path is an upgrade
the server takes: a refusal, with its status and its headers, or the 101
and the connection's cookie, the request's own or one drawn for it,
which the 101 then sets.

`serve` is the shell's life after the 101, in the process that owns the
socket. A reader of its own alone reads the socket and decodes the
client's messages; the shell writes the socket itself. The page's first
resize attaches the shell to the session its cookie names, or to one the
sessions start for it, and from then on the visitor's keys go to the
session and the program's output comes back, each as a binary message,
the session told each piece is written so that it reads its program on,
with the page's resizes, extensions and stop beside them as small JSON
texts, and the attach's completion, whether it started the session or
joined it, and the session's warning as two more. A shell closes with a
close code that says why: 4001 its session expired, 4002 another shell
took it over, 4003 no session was to be had and 4004 it was stopped, or
a code of RFC 6455's.

What a shell takes: from its reader, a message the client sent, an

or the sessions tell it; and its session's end.

## Shell.handshake

```ernest
Shell.handshake(shell : Config.Shell, request : Http.Request) : Either(Refusal, Accepted)
```

Whether the request is an upgrade the server takes, in design §11's
order: a method other than `GET` refused 405 with `Allow: GET`; a
version other than 1.1, an `Upgrade` that lists no `websocket`, a
`Connection` that lists no `Upgrade`, or a `Sec-WebSocket-Version` that
is not one `13`, refused 426 with `Upgrade: websocket` and
`Sec-WebSocket-Version: 13`; no `Origin` of the shell's, refused 403;
and no one `Sec-WebSocket-Key` of 16 bytes in base64, refused 400.

The rest is taken: the 101 with `Upgrade`, `Connection` and
`Sec-WebSocket-Accept`, and, where the request carried no cookie of the
shell's, `Set-Cookie` of the one drawn, 16 bytes of `Crypto.randomBytes`
in lower-case hexadecimal, for the shell's path alone.

### Examples

```ernest
let shell =
    Config.Shell(path = "/shell",
                 origins = ["https://ernest-lang.org"],
                 command = ["cat"],
                 mostAtOnce = 1,
                 starts = Config.Starts(count = 1, within = 1000),
                 lifetime = 2000,
                 warning = 1000,
                 messageLimit = 1024,
                 hangup = 1000);
let request =
    Http.Request(method = "POST",
                 target = "/shell",
                 version = Http.Version(major = 1, minor = 1),
                 headers = []);
Shell.handshake(shell, request)
// => Left(Shell.Refusal(status = 405, headers = [Http.Header(name = "Allow", value = "GET")]))
```

## Shell.serve

```ernest
Shell.serve(socket : Address(Tcp.SocketMsg), carried : Bytes, sessions : Sessions.Sessions, cookie : String, remote : String, timeouts : Config.Timeouts) : Unit receiving ShellMsg
```

The shell's life on the socket after the 101: `carried` the bytes after
the request's head, which the reader decodes first, the sessions the
shell attaches to, its cookie and its remote address, and the
deadlines; it returns once the connection has closed, the socket closed
and its session told it is detached.
